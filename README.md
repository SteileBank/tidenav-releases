# TideNav releases

TideNav is an OpenCPN plugin for comparing departure times and planning
passages with surface current forecasts.

Download the installer and its corresponding source from
[Releases](https://github.com/SteileBank/tidenav-releases/releases).
The beta installer targets OpenCPN Flatpak on x86_64 with runtime 25.08.
In OpenCPN's plugin manager, select **Import plugin**, choose the installer
`.tar.gz`, and enable TideNav.

TideNav is licensed under GPL-3.0-or-later. It is derived from Mike Rossiter's
ShipDriver plugin. The versioned source archive includes build instructions
and the license notices for the bundled components.
